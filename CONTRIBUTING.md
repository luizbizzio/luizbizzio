# Contributing to the Luiz Bizzio GitHub Profile

[`README.md`](README.md) is the GitHub profile page. Contributions here can fix links, improve accessibility, correct project details, or clarify the selected repository list.

## Review a change

Preview the Markdown in GitHub and check the rendered links, images, headings, and alt text. For a repository listing, verify the destination, description, and visibility before adding it. Keep the profile compact and keep setup instructions or bug reports in the repository for the project they concern.

In the pull request, include the link or section you changed and any corrected source. A screenshot is helpful for a visible layout change.
