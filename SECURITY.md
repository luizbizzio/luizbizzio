# Security Policy

## Scope

This repository is a personal GitHub profile repository. It contains profile content, Markdown, images, links, and public contact information. It is not an application, package, service, backend, or executable software project.

Security reports for this repository should focus on issues that could create real risk for visitors or users who interact with the profile page.

## Supported Content

| Content | Status |
| --- | --- |
| Current `main` branch | Supported |
| Profile `README.md` | Supported |
| Images and profile assets stored in this repository | Supported |
| Links listed in the profile | Supported when they are part of this repository |
| Forks, mirrors, or copied versions | Not supported |
| Third-party repositories linked from the profile | Report in the relevant repository instead |

## What to Report

Please report issues such as:

- Malicious or compromised links in the profile.
- Links that redirect to phishing, malware, credential harvesting, or impersonation pages.
- Suspicious files or assets committed to this repository.
- Accidental exposure of private information, credentials, tokens, API keys, or secrets.
- Profile content that could mislead users into trusting an unsafe download, command, or external resource.
- Unauthorized changes that appear to compromise the integrity of the profile repository.

## What Not to Report

The following are not considered security vulnerabilities for this repository:

- Typos, formatting issues, or broken badges.
- Outdated personal or project information.
- General profile design suggestions.
- Requests to remove public information that is intentionally listed in the profile.
- Vulnerabilities in projects linked from this profile, unless the unsafe content is directly inside this repository.
- Issues caused by forks, mirrors, screenshots, cached pages, or third-party copies.

## Reporting a Vulnerability

If GitHub private vulnerability reporting is enabled for this repository, please use it.

If it is not available, report the issue privately by email:

**contact@luizbizzio.com**

Please include:

- A clear description of the issue.
- The affected file, link, asset, or section.
- Steps to reproduce or verify the problem.
- Screenshots or logs when useful.
- Any evidence that a link, file, or asset is malicious or compromised.

Do not include secrets, private credentials, or personal data in a public issue.

## Disclosure

Please do not publicly disclose a confirmed security issue before it has been reviewed and addressed.

This is a personal profile repository, so response and fix times are handled on a best-effort basis. Reports that involve real user risk, malicious links, exposed secrets, or compromised assets will be prioritized.
